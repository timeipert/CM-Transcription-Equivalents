# Detailed Features

## Pattern Analysis
The tool automatically parses your transcription files to identify frequent notation patterns.
- **Filtering**: Search for specific pattern strings.
- **Classification**: Assign metadata and notes to each pattern.

## Manuscript Annotation
The annotation interface uses IIIF to ensure compatibility with library archives.
- **Polygon Drawing**: Precise region definition for individual signs or full lines.
- **Bidirectional Links**: Clicking a sign in the gallery takes you to its equivalent in the table, and vice-versa.

## Public Documentation
The "Public" section of the app is optimized for dissemination.
- **Searchable Index**: Filter patterns by their physical location.
- **Interactive Gallery**: Hover over manuscript scans to see the linked transcription data in real-time.
